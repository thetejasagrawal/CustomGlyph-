# Custom Glyph 1.0 — Public Beta 1

Custom images and GIFs for the rear Glyph Matrix, with a native Android editor, Gallery and schedules.

**[Download the signed APK](https://github.com/thetejasagrawal/CustomGlyph-/releases/download/v1.0.0-beta.1/CustomGlyph-1.0-build3.apk)** · [Source code](https://github.com/thetejasagrawal/CustomGlyph-/tree/v1.0.0-beta.1) · [Report a bug](https://github.com/thetejasagrawal/CustomGlyph-/issues/new?template=bug_report.yml)

## Devices

- **Nothing Phone (3):** logo output after Apply is confirmed by a user on Android 17. The exact Nothing OS build was not captured.
- **Nothing Phone (4a) Pro:** experimental integration for its 13 × 13 matrix and Always-On toys; physical-device verification is pending.
- **Other Android 13+ phones:** editor and export only; no rear-display output.

This is a public beta. The reported clock/image switching across lock and unlock still needs a repeat device test. Continuous illumination is not guaranteed by Nothing OS.

## Included

- PNG, JPEG, WebP, SVG and animated GIF import, including transparency.
- Matrix preview that stays visible while you adjust the image.
- Pinch, drag, scale, rotation and precise positioning.
- Brightness, contrast, silhouette, inversion and dithering.
- Saved designs, recent edits, PNG/SVG export and Android sharing.
- Weekday and overnight schedules, plus a stop timer.
- Display setup with permission shortcuts and an Always-On toy picker shortcut with fallbacks.
- Monochrome Compose UI with Doto headings and JetBrains Mono controls.

Build 3 fixes premature bitmap cleanup during SDK rendering and adds visible, copyable error details. It is the same APK that restored output on the reported Phone (3).

## Install and set up

1. Download **CustomGlyph-1.0-build3.apk** from this release and open it on your phone. Allow installation from your browser or file manager when Android asks.
2. Open Custom Glyph and complete **Set up display**. Follow the notification, Glyph and optional battery-access steps shown for your device.
3. Tap **Choose Always-On toy** and select **Custom Glyph**. If the direct picker is unavailable, use **Settings → Glyph Interface → Flip to Glyph → Always-on Glyph Toy**.
4. Choose an image and tap **Apply to Glyph**.

If you already have build 3, this download is identical; no reinstall is needed. Earlier Custom Glyph builds can update in place. Stop or uninstall the separate **Glyph Studio** prototype if you still have it, to avoid competing display requests.

If Play Protect offers a scan, let it complete. A valid APK signature does not guarantee that a new app is recognized by Google. If it reports a harmful app, include the exact warning in a bug report; do not disable protection.

## Known limits

- Lock/unlock transitions, reboot behavior, battery policy and schedule timing in deep sleep still need physical testing.
- Nothing OS controls Always-On toy priority and may interrupt output. Selecting Custom Glyph for the rear button alone does not select it as the Always-On toy.
- GIF playback can pause when the system suspends the app. Static images are the most predictable Always-On content.
- Phone (4a) Pro uses the Always-On toy route only; direct app display is not enabled.
- The app uses the official example's `test` SDK key. No production entitlement or Nothing endorsement is claimed.
